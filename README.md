# aarogyaid-claims-management-assignment

## Project Overview

Aarogya ID – Claims Management Platform is a full-stack web application developed as part of the Aarogya ID internship assignment. The platform streamlines the health insurance claim process by providing dedicated portals for patients and insurers.

Patients can securely submit insurance claims, upload supporting documents, and track the status of their claims in real time. Insurers can review submitted claims, view uploaded documents, approve or reject requests, specify approved amounts, and provide comments.

The application is built with a modern, scalable architecture using React, TypeScript, NestJS, and MongoDB, following best practices for authentication, API design, and responsive user interfaces. Additionally, it includes a bonus AI-powered claim summary and risk indicator to demonstrate how AI can enhance healthcare claims processing.

This project showcases end-to-end full-stack development, secure authentication, RESTful API implementation, file uploads, database integration, and a clean, production-inspired user experience.
